\doxysubsection{Detailed Description}
This class lets a high-\/level programmer add easily more devices to the main program. You can use the implemented public functions wherever you need. For adding a new device you can follow this steps\+: 


\begin{DoxyEnumerate}
\item Instantiate a device\+Builder with \mbox{\hyperlink{class_device_builder}{Device\+Builder()}};
\item Set the type of device with \mbox{\hyperlink{class_device_builder_a54ac8bbaa057ca01a0067429b05ae01c}{set\+As\+Data\+Device()}} or \mbox{\hyperlink{class_device_builder_a80c1e37a4f5ed9d6417d368f05f1e57d}{set\+As\+Kernel\+Device()}};
\item Set the main generator (function where the device extracts data) with \mbox{\hyperlink{class_device_builder_a660593f04dacdaecde2f1654c43eb646}{set\+Data\+Generator()}} or \mbox{\hyperlink{class_device_builder_ae090a3296c74c945a17595828e416c73}{set\+Security\+Generator()}}
\item (Optional) Add some skills (more functionalities) to your device with \mbox{\hyperlink{class_device_builder_ac77b5836b06caace168fa1bbbf2e7ab2}{set\+Skill()}}.
\item (Optional) Set a warning if measurement surpasses a limit with \mbox{\hyperlink{class_device_builder_a97e1c662cbee5e3e23b4b41b0d300a6f}{set\+Limit()}}
\item Repeat this process with as many devices as you need.
\item Use \mbox{\hyperlink{class_device_builder_a019aad6467d0508effef62ff0a6a4b63}{build\+All\+Devices()}} to build every instance.
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
This class must be inited by the main class and will configure 3 classes. First, the builder will set every input device into the main class and set their corresponding global commands. Then it will build every output device into the \mbox{\hyperlink{class_device}{Device}} class assigning the high-\/level functionalities and properties. Finally, the builder will assign \mbox{\hyperlink{class_a_i}{AI}} properties of devices into the \mbox{\hyperlink{class_a_i}{AI}} class if requested. When the relationships between high and low layer are established, the builder can be destroyed. 
\end{DoxyNote}
