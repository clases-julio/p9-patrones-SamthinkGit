Every device will be built from the builder and the data managed will be managed from \mbox{\hyperlink{class_a_i}{AI}} and \mbox{\hyperlink{class_i_o_di}{IODi}}. This class will also be the base for constructing Data\+Devices and Kernel\+Devices.
